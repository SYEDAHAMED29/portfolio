This short post demonstrates when to reach for MDX while keeping ordinary Markdown the default.

## Use a block only when it adds meaning

Normal Markdown still handles [links](https://docs.astro.build/), `inline code`, headings, lists, and fenced code blocks.

```ts
const format = (value: string) => value.trim();
```

<Callout type="note">

MDX components are useful for **specialized content blocks** that should be reusable across articles.

</Callout>

<Callout type="warning" title="Keep MDX optional">

- Start with `.md` for ordinary technical writing.
- Choose `.mdx` when the article imports a component or needs MDX expressions.

</Callout>
